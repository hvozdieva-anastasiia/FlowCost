# Ручная проверка в Figma Desktop

Автоматические тесты покрывают движок расчёта, разбор реакций, протокол и окно с подставным каналом связи. Чтение настоящего прототипа Figma ими не проверено: это делается вручную по списку ниже. Отмечать результат в таблице внизу.

## Подготовка

1. `pnpm build`.
2. Figma Desktop: Plugins → Development → Import plugin from manifest → `manifest.json`.
3. После первого импорта записать выданный ID: `pnpm plugin:id <ID>`.
4. Открыть тестовый файл с прототипом: страница из 5–6 экранов, связи `NAVIGATE`, один `OVERLAY` с кнопкой закрытия, один `SWAP`, один таймер `AFTER_TIMEOUT`, один `CONDITIONAL`, экран с полем ввода (слой с именем «Email input»), прокручиваемый экран с целью ниже границы, точка входа потока.

## Проверки

| №   | Что сделать                                           | Ожидаемый результат                                                                   |
| --- | ----------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 1   | Запустить плагин                                      | Окно открывается, список экранов совпадает с фреймами страницы, начало потока выбрано |
| 2   | Выбрать цель                                          | Показываются шаги, время, точки трения; число шагов совпадает с ручным подсчётом      |
| 3   | Включить Fewest steps и открыть Other paths           | Пути отличаются, самый быстрый стоит первым в списке                                  |
| 4   | Открыть шаг и нажать Show layer                       | Слой выделяется и показывается на холсте                                              |
| 5   | Выделить экран, нажать Use selection                  | Экран подставляется в Start или Goal                                                  |
| 6   | Путь через оверлей и SWAP                             | Шаги и точка трения «Overlay» присутствуют                                            |
| 7   | Путь через таймер                                     | Шаг помечен «timer», действий пользователя на нём нет                                 |
| 8   | Путь через CONDITIONAL                                | Показано примечание о неподдерживаемом значении переменных                            |
| 9   | Экран с полем «Email input»                           | В шаге есть операторы H, K; Marks → Not inputs убирает их                             |
| 10  | Цель ниже границы прокручиваемого экрана              | Оператор S и точка трения «Scroll»                                                    |
| 11  | Мелкая кнопка (меньше 24 px для мыши, 44 для касания) | Точка трения «Small target»; для Touch порог выше                                     |
| 12  | Время перехода на реакции                             | Единицы совпадают (0,3 s, не 300 s). Это проверка допущения о секундах                |
| 13  | Удалить целевой экран, нажать Read page               | Health показывает битую связь, Show выделяет источник                                 |
| 14  | Экран, на который ничего не ведёт                     | Health: недостижимый экран                                                            |
| 15  | Selected screen is an ending                          | Предупреждение «нет выхода» пропадает, отметка сохраняется после закрытия файла       |
| 16  | Save snapshot, изменить связи, Compare                | Таблица разницы с процентами                                                          |
| 17  | Copy Markdown, Copy CSV                               | Текст попадает в буфер, либо появляется поле для ручного копирования                  |
| 18  | Сменить страницу                                      | Появляется «The page changed» и кнопка Read it again                                  |
| 19  | Тёмная тема Figma                                     | Текст читается, фокус виден                                                           |
| 20  | Страница на 500+ слоёв с реакциями                    | Чтение завершается без заметного зависания                                            |
